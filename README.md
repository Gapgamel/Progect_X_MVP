
# Учёт товаров (MVP)

## Описание проекта
Консольное приложение на Python для управления товарами.

## Возможности
- Добавление новых товаров.
- Просмотр списка товаров.
- Удаление товаров по ID.
- Проверка введённых данных.
- Обработка ошибок пользователя.

## Технологии
- Python 3
- Стандартная библиотека Python

## Запуск программы
Открой терминал и выполни команду:

python main.py

## Ограничения
Данные хранятся в оперативной памяти.
После закрытия программы список товаров очищается.
