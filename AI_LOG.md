
# AI_LOG — Журнал работы с ИИ

## Проект
Учёт товаров (MVP).

## Используемый инструмент
ChatGPT.

## Задача 1. Создание структуры программы

**Контекст:** Разрабатывается консольное приложение для учёта товаров на Python 3.

**Задача:** Создать структуру программы с функциями добавления, просмотра и удаления товаров.

**Ограничения:** Использовать только стандартную библиотеку Python.

**Результат:** Создан файл main.py с основными функциями приложения.

## Задача 2. Добавление товаров

**Результат:** Реализована функция add_product, которая добавляет товар с названием, ценой и количеством.

## Задача 3. Просмотр товаров

**Результат:** Реализована функция show_products для отображения списка товаров.

## Задача 4. Удаление товаров

**Результат:** Реализована функция delete_product для удаления товара по ID.

## Задача 5. Обработка ошибок

**Результат:** Добавлены проверки пустого названия, отрицательной цены и количества, а также некорректного ввода.

## Ограничения проекта

Данные хранятся в оперативной памяти и исчезают после завершения программы.

## Проверка

Проверка запуска и всех критериев приёмки ещё должна быть выполнена.
